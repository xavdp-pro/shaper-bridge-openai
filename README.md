# OpenAI Responses — intention and laws

This repository owns the mental source of the **shaper-bridge-openai** component:
its intention, laws and declared interface responsibilities. It contains no
implementation code, credentials, operational topology or private conversations.

Read [INTENT.md](INTENT.md), [LAWS.md](LAWS.md) and [INTERFACE.md](INTERFACE.md).
The [bridge catalogue](https://github.com/xavdp-pro/shaper-bridge-catalog) connects
these sources. Realization and laboratory companions have separate custody;
source ownership does not assert that an instance is installed or qualified.

Inference with complete Responses output-item continuity, including preserved message phases and encrypted reasoning items.

Use the [common glossary](https://github.com/xavdp-pro/shaper-glossary)
and [composition](https://github.com/xavdp-pro/shaper-ecosystem/blob/main/chapters/10-COMPOSITION.md).
The human–AI tandem directs work. A cognition bridge connects that work to an
engine; governors coordinate within jurisdiction and makers realize authorized
host operations. An adapter is a component, not another governance hierarchy.
